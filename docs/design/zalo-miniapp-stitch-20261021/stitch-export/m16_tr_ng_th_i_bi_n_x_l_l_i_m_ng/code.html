Zalo SDK v2.x
1. Safe-Area Navigation Insets env(safe-area-inset-*)

Xử lý top padding bằng header shell cố định (56px) tránh tai thỏ. Đáy màn hình tính toán dự phòng 56px + safe-area-bottom để tab bar Zalo không đè lên nút hành động.

2. Cơ chế Offline-First zalo.setStorage / IDB

Mọi ký tự gõ được snapshot vào IndexedDB theo chu kỳ 1.5s debounced. Khi phát hiện network timeout (HTTP 408 / Offline event), kích hoạt cờ trạng thái tại chỗ, tuyệt đối không gửi ngầm nền tránh nhân đôi dữ liệu nhạy cảm.

3. Công thái học thị giác Be Vietnam Pro 16px

Toàn bộ input body text áp dụng cỡ 16px tiêu chuẩn (line-height 26px) giúp phụ huynh lớn tuổi đọc rõ ràng mà học sinh không bị cảm giác ngột ngạt khi viết nhật ký cảm xúc dài.
