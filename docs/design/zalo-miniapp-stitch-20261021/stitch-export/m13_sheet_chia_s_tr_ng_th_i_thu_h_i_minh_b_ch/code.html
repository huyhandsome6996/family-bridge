verified_user Tài liệu kỹ thuật bàn giao (Handover Note)

• Granular ACL (Kiểm soát truy cập từng mục): Mỗi nhật ký tâm trạng sở hữu Access Control List riêng biệt gắn với partner_id, không kế thừa tự động sang toàn bộ hồ sơ.

• Snapshot Isolation (Bất biến nội dung): Hành động chỉnh sửa sau khi chia sẻ không kích hoạt webhook gửi bản ghi mới. Phiên bản đối tác nhìn thấy gắn cố định với hash ID thời điểm gửi ban đầu.

• Revocation SLA: Lệnh thu hồi áp dụng cache purge tức thời trong vòng <300ms qua Socket/Zalo Cloud Sync, vô hiệu hóa token đọc ngay lập tức.

• Zero False Claims: Tuân thủ cam kết minh bạch UX, không hiển thị các thông báo giả định về việc can thiệp bộ nhớ thiết bị ngoài Zalo.
