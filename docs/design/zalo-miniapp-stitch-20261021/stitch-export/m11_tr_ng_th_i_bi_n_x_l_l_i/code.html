v1.2
  • check_circle
    Khắc phục kẹt bộ lọc (Empty Filter): Khi kết quả API trả về mảng rỗng `[]`, không hiển thị màn hình trắng. Cung cấp ngay action `RESET_FILTER` hoặc `WRITE_CUSTOM_NOTE`.
  • check_circle
    Xác thực cặp đồng hành (Pairing Validation): Kiểm tra `user.partnerId` trước khi mở modal chọn thẻ. Nếu `null`, chặn mở composer và route trực tiếp qua Deep Link `/pairing`.
  • check_circle
    Phòng vệ mất dữ liệu (Draft Protection): Ghi bản nháp vào `IndexedDB` hoặc `zalo.setStorage` theo từng phím gõ. Nếu network timeout, giữ nguyên draft và cảnh báo idempotent để tránh gửi thư lặp 2 lần.
