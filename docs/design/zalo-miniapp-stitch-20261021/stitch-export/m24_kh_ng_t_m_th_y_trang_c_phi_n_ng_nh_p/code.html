Bảo vệ phiên đăng nhập an toàn

Family Bridge cam kết không để lộ đường dẫn nhạy cảm hoặc token bảo mật khi có lỗi phát sinh. Toàn bộ phiên làm việc của bạn vẫn được giữ an toàn.

Route Type: Universal Catch-All Fallback (* path)
Session Preservation:

Giữ nguyên session token và cached state; tuyệt đối không tự động logout hay clear cache khi gặp 404.

Redirection Logic:
  • Về Trang chủ: Gọi navigate('/home')
  • Quay lại: window.history.length > 1 ? history.back() : navigate('/home')
Privacy & Boundary Policy:

Không render raw params hay input token ra DOM. Phân biệt rõ ràng với mã lỗi 403 Forbidden (thu hồi quyền xem nội dung).
