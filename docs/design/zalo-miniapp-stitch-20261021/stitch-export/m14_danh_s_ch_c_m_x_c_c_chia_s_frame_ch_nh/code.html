Developer Specs & Handoff (M14)

v1.2.0
1. Routing & Access Path: Route: /mood-shared (Sub-route from /profile, Top App Bar back action returns to Previous Tab).
2. Zero-Leak Privacy Payload:

List endpoint MUST NOT expose unencrypted notes or emotion logs:

GET /api/mood-shares → Returns strictly: 
{ items: [{ id: "uuid", sender_name: "string", created_at: "ISO", mood_tag: "string" }] }
3. Real-Time Single-Item Fetch & Authorization:

Action 'Mở nội dung' calls GET /api/mood-shares/:id. Backend checks active family consent and revocations at this exact second before sending notes content.

4. UI Constraints:

Zalo Mini App 390px, 16px margins, zero border tokens, no aggregated mood scores or tracking streaks.
