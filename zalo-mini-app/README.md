# Family Bridge Zalo Mini App

Xem [cài đặt và triển khai](../docs/development.md), [phạm vi](../docs/project-scope.md) và [kiến trúc](../docs/architecture.md).

Frontend dùng React JavaScript, Vite, zmp-ui và zmp-sdk. Bản nền tảng chỉ kiểm tra kết nối API; chưa có đăng nhập hoặc tính năng nghiệp vụ. `npm run start` là preview local; deployment lên Zalo dùng CLI/Extension với App ID.
